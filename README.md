# LPC2138 Embedded C Practice

This repository contains Embedded C practice programs using LPC2138 (ARM7).

## Implemented Modules
- LEDs
- LED & Switch
- 7 Segment
- LCD (16x2)
- External Interrupts (EINT0–EINT3)

## Key Concepts:
-GPIO configuration & Peripheral interfacing
-External interrupt configuration (EXTMODE, EXTPOLAR, EXTINT)
-VIC configuration & priority handling (VICIntEnable, VICVectCntl, VICVectAddr)
-Interrupt Service Routine (ISR) flow

## Platform & Tools
- LPC2138 (ARM7)
- Keil uVision
- Proteus (simulation)
