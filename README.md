# LPC2138 Embedded C Practice

This repository contains Embedded C practice programs using LPC2138 (ARM7).

## Topics Covered
- LEDs
- LED & Switch
- 7 Segment
- LCD (16x2)

These programs focus on understanding:
- GPIO configuration
- Delay functions
- Switch interfacing
- 7 Segment display control
- LCD interfacing (16x2)

## Platform & Tools
- LPC2138 (ARM7)
- Keil uVision
- Proteus (for simulation)
